# BlockX Lists

This repository contains the default BlockList for the Resonite [BlockX](https://github.com/jae1911/BlockX-Lists) mod.

## Guidelines

- This list is meant for trackers and ads in worlds and items
- We will **not** add somebody's avatar
- We will **not** add somebody's worlds as a whole
- If you have an issue with someone, [contact moderation](https://moderation.resonite.com)
